What is in the file

A free AAC core board you can print today: a full page color-coded board of 16 picture words, a smaller 12 word starter board that prints two to a page, and a teacher page on how to model a core board by pointing and talking. The pictures and the board design are the ones in our paid Communication Board Template and our core word picture cards, so you can see exactly what they look like before you buy. The 12 starter words sit in the same places as the top three rows of the full board, so the words stay put when you move up. Print, laminate and keep the board where your student is. The labels edit in PowerPoint. This is a printable picture board, not a speech device or an app, and it does not replace an evaluation by a speech-language pathologist. Words such as I, you, what and where are not on this free board; the paid template includes them as word cards.

Made for pre-K, kindergarten, 1st grade, 2nd grade, 3rd grade, 4th grade and 5th grade. You get 5 pages, as an editable PowerPoint and a print-ready PDF.

What is included

  • Core Word Board, 16 words
  • Starter Board, 12 words, two to a page
  • How to model a core board, teacher page
  • How to use page

How the editing works

  • Open the PowerPoint file and click any text box to type your own wording.
  • Change the text, font, size and color. The background design is locked so your layout never shifts.

Printing

  • Print at 100 percent or Actual Size so the trim sizes stay true.
  • Cardstock and lamination hold up all year for anything that gets handled daily.

Set in standard fonts so it opens the same way on any computer, with no font downloads to chase.
