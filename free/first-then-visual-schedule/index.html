FREE First Then Visual Schedule

What it is

A visual schedule set for autism and special education classrooms: sixteen strip cards for the day to hang in order, a blank set, nine routine picture cards, and a First Then board that shows the next step.

Best for
Pre-K through grade 5
Prep
Print on cardstock, laminate, and add hook and loop dots to the cards and the board.

Download free on TPT

It opens on Teachers Pay Teachers, where the file lives. A free TPT account is needed to download.

Ways to use it

  1. Post the day strip cards in order at the start of the day so a child can see what comes next.
  2. Use the First Then board for a hard transition, with just the current task and the next step showing.
  3. Use the blank set to build a schedule for a day that runs differently, such as a schedule change or an assembly.
