What is in the file

A printable gradebook that is actually a gradebook: the grid, the roster, the attendance sheet, the standards check and the class information page, free, in a lane where everything else costs about four dollars. The grade columns are numbered rather than blank, and there is a key page to write the assignment names on, which is the part every printable gradebook gets wrong. Everything is editable if you want to type your class list once, and every page comes in ink saver black and white for the copier.
