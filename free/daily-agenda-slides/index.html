If you want more of it

How the timers work

  • Open the timer menu and tap a length. The bar is built from blocks, and one block leaves every time a slice of the time is up, so the room can see the time going without a ticking clock.
  • There are 3 of them: 1, 2, 3 minutes.
  • The countdown only runs in Slide Show mode, and closing the file without saving puts every block back, so the same timer works again tomorrow.

Before you buy, one honest note about Google Slides

  • This is a PowerPoint file. Upload it to Google Slides and every word and color is still editable there, but the countdown is PowerPoint animation and Google Slides will not run it. The timer slides still work in Google Slides as plain "you have five minutes" slides; the blocks just do not disappear on their own.
  • Everything else, the agenda, the menu buttons, the themes, works in both.

Make it yours

  • The example text is there to be typed over. Click any dashed box and start typing; nothing in the file is a picture of text.
  • Most teachers fill in the parts that never change once in August, the class name, the absent-work policy, the materials, and then only touch the date and the agenda each day.
  • Duplicate a slide for each day of the week and you have the whole week in one file.
  • Recolour anything. Every bar, chip and card is a real shape, so a theme can become your own colors in a minute. The themes as they ship are Composition Notebook, Farmhouse Shiplap.
